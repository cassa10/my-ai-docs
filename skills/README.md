# Skills

Documentación de skills para agentes AI (Claude Code, Codex u otros). Un skill es un paquete de instrucciones que el agente carga cuando la tarea lo requiere.

## 📂 Templates Disponibles

- **[skill-template.md](./skill-template.md)**: Estructura base para documentar un skill, incluyendo su `SKILL.md`, instalación y ejemplos.

## 📝 Skills Documentados

Todavía no hay skills documentados. Para agregar uno:

```bash
cp skills/skill-template.md skills/mi-skill.md
```
