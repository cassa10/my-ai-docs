# Agentes para Codex

Los agentes de [agents/claude/](../claude/) usan el formato de Claude Code: frontmatter con `tools`, `model` y `effort`. Codex no los carga tal cual. Cuando se definan agentes para Codex, van en esta carpeta.

Para replicar la configuración de Codex, ver [setup/codex/README.md](../../setup/codex/README.md).
